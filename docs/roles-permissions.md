# Role และ Permission

## รายการบทบาทผู้ใช้งาน (User Roles)

อ้างอิงตาม `PROJECT.md`:

| บทบาท (Role Key) | ชื่อแสดงผล | คำอธิบายและความรับผิดชอบ |
|---|---|---|
| `SUPER_ADMIN` | Super Admin | จัดการทุกส่วนของระบบ รวมถึงการตั้งค่าระบบและผู้ใช้งานทั้งหมด |
| `ADMIN` | Admin | จัดการข้อมูลทั่วไป ผู้ใช้งาน และการตั้งค่าพื้นฐาน |
| `SALES` | Sales | จัดการข้อมูลลูกค้า ติดตามงาน และจัดทำใบเสนอราคา |
| `ESTIMATOR` | Estimator | จัดการวัสดุ ปริมาณสินค้า และคำนวณต้นทุน |

## สิทธิ์การเข้าถึงเมนูการตั้งค่าผู้ใช้งาน

- สิทธิ์ในการเรียกใช้งาน API `/settings/users` และหน้าจอการตั้งค่าผู้ใช้งาน ต้องผ่านการตรวจสอบสิทธิ์ด้วย JWT Token (`Bearer <token>`)
- ผู้ดูแลระบบไม่สามารถลบบัญชีตนเองในขณะที่กำลังเข้าสู่ระบบอยู่ได้ เพื่อป้องกันปัญหาการเข้าถึงระบบ
- **การคุ้มครองบัญชีผู้ดูแลระบบหลัก (`admin`)**:
  - ห้ามระงับการใช้งานบัญชีผู้ดูแลระบบหลัก (`admin`) หรือเปลี่ยนสถานะเป็น `INACTIVE` ทั้งในระดับ Frontend UI และ Backend API
  - ห้ามลบบัญชีผู้ดูแลระบบหลัก (`admin`) ออกจากระบบ เพื่อป้องกันภาวะ Lockout หรือสูญเสียสิทธิ์ในการเข้าถึงระบบโดยสมบูรณ์

## สิทธิ์การเข้าถึงข้อมูลลูกค้า (Customer Management)

- ผู้ใช้งานที่มีบทบาท `SUPER_ADMIN`, `ADMIN` และ `SALES` มีสิทธิ์เต็มในการดูรายการ, ค้นหา, สร้าง, แก้ไข และลบข้อมูลลูกค้า (อ้างอิงตาม `PROJECT.md` ที่มอบหมายให้ `Sales` จัดการลูกค้าและใบเสนอราคา)
- การเรียกใช้งาน API `/customers` และหน้าจอจัดการข้อมูลลูกค้าต้องผ่านการยืนยันตัวตนด้วย Bearer JWT Token

## สิทธิ์การเข้าถึงข้อมูลโครงการ (Project Management)

- ผู้ใช้งานที่มีบทบาท `SUPER_ADMIN`, `ADMIN`, `SALES` และ `ESTIMATOR` มีสิทธิ์ในการดูรายการ, ค้นหา, สร้าง, แก้ไข และลบข้อมูลโครงการก่อสร้าง
- การเรียกใช้งาน API `/projects` และหน้าจอจัดการข้อมูลโครงการต้องผ่านการยืนยันตัวตนด้วย Bearer JWT Token

## สิทธิ์การเข้าถึงข้อมูลสินค้าและวัสดุ (Product & Material Management)

- ผู้ใช้งานที่มีบทบาท `SUPER_ADMIN`, `ADMIN` และ `ESTIMATOR` มีสิทธิ์เต็มในการดูรายการ, ค้นหา, สร้าง, แก้ไข และลบข้อมูลสินค้าและวัสดุ (รวมถึงการดูราคาต้นทุน)
- ผู้ใช้งานบทบาท `SALES` สามารถดูรายการสินค้า ค้นหา และตรวจสอบราคาขายมาตรฐาน/สถานะคงเหลือเพื่อนำไปจัดทำใบเสนอราคาได้ แต่ไม่มีสิทธิ์แก้ไขหรือลบข้อมูลสินค้า
- การเรียกใช้งาน API `/products` และหน้าจอจัดการข้อมูลสินค้าและวัสดุต้องผ่านการยืนยันตัวตนด้วย Bearer JWT Token

## สิทธิ์การเข้าถึงข้อมูลใบเสนอราคา (Quotation Management)

- **ผู้ดูแลระบบ (`SUPER_ADMIN`, `ADMIN`)**:
  - ดูรายการ, ค้นหา, กรอง และดูรายละเอียดใบเสนอราคาทุกฉบับ
  - สร้างและแก้ไขใบเสนอราคาในทุกสถานะ
  - อนุมัติ (`APPROVED`) หรือปฏิเสธ (`REJECTED`) ใบเสนอราคา
  - ลบใบเสนอราคาออกจากระบบ (สามารถลบได้ทุกสถานะ)
- **พนักงานขาย (`SALES`)**:
  - ดูรายการ, ค้นหา, สร้างใบเสนอราคาใหม่ และแก้ไขใบเสนอราคาที่เป็นของตนเองหรือสถานะแบบร่าง (`DRAFT`)
  - ส่งใบเสนอราคาขออนุมัติ (`PENDING_APPROVAL` / `PENDING_REVIEW`)
  - ทำเครื่องหมายส่งให้ลูกค้าแล้ว (`SENT`)
  - บันทึกผลตอบรับจากลูกค้า: ลูกค้ายอมรับ (`ACCEPTED`) หรือลูกค้าปฏิเสธ (`REJECTED`)
  - ลบใบเสนอราคาได้เฉพาะในสถานะแบบร่าง (`DRAFT`) หรือยกเลิก (`CANCELLED`)
- **ฝ่ายประมาณราคา (`ESTIMATOR`)**:
  - ดูรายการใบเสนอราคา ค้นหารายการวัสดุ ตรวจสอบต้นทุน และคำนวณราคา
  - สร้างและแก้ไขรายการวัสดุ/บริการในใบเสนอราคาเพื่อประมาณการราคาและกำไรขั้นต้น
  - ส่งใบเสนอราคาให้ฝ่ายขายหรือผู้อนุมัติตรวจสอบ
- การเรียกใช้งาน API `/quotations` และหน้าจอจัดการใบเสนอราคาต้องผ่านการยืนยันตัวตนด้วย Bearer JWT Token
